# Agentic AI Major Project

## Project Overview
This project forms the Major Project component of the NSW NESA Software Engineering HSC Course.

Students will design and implement an agentic AI system that solves a real-world problem in one of the following domains:

- Agriculture
- Healthcare
- Industry


* Expected Features
- Large Language Model integration
- Multi-Agent Architecture
- Retrieval Augmented Generation (RAG)
- Tool Calling
- Conversational Memory
- Voice Interface
- User Interface
- Testing and Evaluation
- Technology Stack
- Python Ollama LangChain ChromaDB SQLite Whisper

** Software Engineering Lifecycle
- Requirements Analysis
- System Design
- Implementation
- Testing
- Evaluation
- Deployment
